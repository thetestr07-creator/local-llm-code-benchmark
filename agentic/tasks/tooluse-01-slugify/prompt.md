Users report that URL slugs generated by this library are malformed for titles
that contain punctuation or extra spaces. For example, the title
`"Hello,  World!"` should produce the slug `"hello-world"`, and `"Python 3.12 rocks"`
should produce `"python-3-12-rocks"`. Currently these produce broken slugs.

Find where slugs are generated in the codebase and fix the logic so that a slug is
the lowercased alphanumeric words of the title joined by single hyphens (no
punctuation, no empty segments, no leading/trailing hyphens). Do not change public
function signatures. Keep the library importable.
